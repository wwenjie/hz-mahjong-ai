# 使用说明（评审版）

杭州麻将 AI 参赛程序。接入官方对战平台，全程自动决策，无需人工干预。

## 1. 运行环境

| 项目 | 要求 |
|---|---|
| Python | ≥ 3.12 |
| 第三方依赖 | **运行时零依赖**（纯标准库；numpy/sklearn 仅用于离线训练，不在运行路径） |
| 网络 | 能访问比赛服务器（自签证书，程序内已按平台要求关闭校验） |

## 2. 安装

```bash
pip install -e .
```

或不安装直接运行：`PYTHONPATH=src python3 -m majiang --help`。

## 3. 令牌配置（环境变量优先）

```bash
export MAJIANG_TOKEN="<参赛令牌>"
export MAJIANG_SERVER="https://<服务器>:<端口>"   # 可选，有默认值
```

令牌只从环境变量读取；不提供 `--token` 直传（会进入进程列表）以外的任何落盘路径。
程序日志对令牌自动脱敏，仓库内无任何凭据。

## 4. 启动

```bash
majiang --token-env MAJIANG_TOKEN            # 正式赛事（报名令牌）
majiang --token-env MAJIANG_TOKEN --auto-match   # 自由匹配（全局令牌）
```

常用参数：`--mode qualifier|final`（晋级轮稳健/决赛激进）、`--duration 秒`、
`--log-dir 目录`、`--rate 每秒请求上限（默认 14，低于平台 16/s）`。
`Ctrl-C` 或 `SIGTERM` 优雅退出并打印汇总。

## 5. 自检（无需联网）

```bash
bash scripts/verify_clean_env.sh   # 干净 venv：安装→CLI→模型求值→本地模拟 8 局
python3 -m pytest tests/           # 全量测试（当前 427 项）
```

`verify_clean_env.sh` 在全新虚拟环境中验证：零依赖安装成功、CLI 可用、
两个模型（`models/*.json`）用纯 Python 树遍历求值且结果与开发环境逐位一致、
本地模拟器跑完 8 局且零和校验通过。

## 6. 行为要点（与平台规则的对应）

- 只自摸、无点炮：程序只在自家摸牌/响应窗口提交动作，出牌阶段外不动作
- 财神（白板）不打、不吃碰杠财神；打出财神后的抓打圈自动遵守
- 牌墙最后 20 张不摸不禁杠；吃牌全局 ≤2 副
- 局间 `settled` 阶段不提交动作；长轮询 `pending` 自动重同步；动作被拒（409）不原地重试
- 断网/平台 5xx 自动退避重试；进程重启后从平台侧状态自动接管，不重复提交

## 7. 合规

推理输入仅限公开信息（自身手牌、弃牌堆、各家副露、牌墙剩余、财神状态）；
无读取/推断对手手牌的代码路径；不调用平台文档未声明的外部服务；模型推理为进程内纯计算。
