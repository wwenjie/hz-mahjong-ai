## 根因：这是**七对听牌**，唯一区分是听口张数

- 手牌 `1w1w 8w8w 9w 7t7t 8t8t 北北北 白` 已是**七对形听牌**（`shanten_any=0`；摸听口即 `七对/豪华七对` 成立，由 `is_winning_shape` 逐张验证）。
- 打哪个**单张**都不破向听 0，所以价值**只由「打后的活听口张数」决定**：

| 打 | 打后听口 | 剩余张数 |
|---|---|---|
| 打 `4w` | `9w` + `北` + `白` | **1 + 1 + 3 = 5** |
| **打 `9w`** | `4w` + `北` + `白` | **3 + 1 + 3 = 7** |
| 打 `北` | `4w` + `9w` + `白` | 3 + 1 + 3 = 7（但破现成面子，未测） |

关键可见张数：`4w` 他人弃牌/副露 = **0**（3 张全活）；`9w` 已见 **3**（座1、座3 各弃一张 + 自己一张，仅剩 1）。⇒ **打 `9w` = 丢掉几乎死掉的边张，保留 3 张全活的 `4w` 当听口**；打 `4w` 则把自己的活听口扔掉。

## 豆包分析：哪里对、哪里错

**对的**：`北北北` 现成刻子；`7t7t8t8t` 双对复合搭；`8w8w9w` 是搭子；保留 `7788t` 不拆——结构读牌都对。

**错的两处（都是硬错）**：

1. **前提用错形**：豆包按「4 面子 + 1 将」的标准形去数（说要凑「3 面子 + 1 将」），但本手**已是七对形听牌**，标准形路线在这里是多余的分支 ⇒ 它对「凑面子」的整段推理与本决策无关。
2. **把「防守/放炮」当成首要，而本平台 `不允许点炮`（只能自摸）** ⇒ 豆包整段「4w 危险性」「打 8w 放炮风险高」「局势紧张才换 9w」的推理**在本平台不成立**。真实存在的只是「喂牌」（让对手更快吃碰/自摸），而这正是 v7 显式建模的项。
3. **把最优的 `9w` 当「防守次选」**：恰恰相反，`9w` 是**进攻最优**——它比豆包的 `4w` 多 2 张活听口。

**豆包漏掉的关键一步**：它认了 `4w` 是「纯孤张」，但**没算「打完之后每张听口还剩几张」**。听牌态下，「孤张」不等于「该打」——要比较的是**听完之后的活张数**：`9w` 只剩 1 张，`4w` 还有 3 张。

## 判词

- **v7（打 `9w`）正确**，且不是微弱优势：n=600 配对 **+6.40（t +4.28）**。
- 豆包的结构读牌可用，但**结论与首要理由都错**（用错形 + 本平台无点炮 + 未算听口余张）。
- 用户的直觉（「不打孤张」）在**标准麻将**里通常对；在本手、本规则下**恰好相反**——因为本手是七对听牌、且本平台无放炮，打掉那个「孤张」会扔掉自己的活听口。
