# 估值分歧根因：出牌评分函数对候选无分辨力（2026-10-10，B' 独立复核）

> 用户 2026-10-10 11:05 指出：报障里**很多是估值分歧**，是**明显不合理的出牌决策**，会让引擎处于劣势，要正视。
> 本条给出**可判定证据**：不合理出牌源自**评分函数本身无法区分候选**，不是「口味」。
> 全部本地只读复算，零 `src/` 改动。

## 1. 评分函数结构

`_score_discard`（`src/majiang/strategy/policy.py`）对每个出牌候选算：
```
total = −10×向听 + 形质(shape_value) − 3×喂牌(feed) − 财神罚(god_penalty)
```
出牌 = `total` 最大者；同向听层再走 `_break_ties_by_ukeire`（破平层）。

## 2. 证据：**形质项在最需要区分的点上恒并列**

在真实对局语料（400 房、我方出牌点 **22,874** 个）上统计「最小向听层候选≥2」时 `shape_value` 的分辨力：

| 指标 | 数值 |
|---|---|
| **形质(blocks) 全并列** | **9,196 / 22,874 = 40.2%** |
| ├ 由「喂牌」分出高下 | 7,660 (33.5%) |
| └ 连 (形质,喂牌) 都并列 ⇒ 破平层/牌索索引决定 | 1,536 (6.7%) |

⇒ **四成出牌点的「形质」给所有最优候选同一个分数**，排序实际由**喂牌**或**索引/破平层**决定。

## 3. 证据：报障点里 58% 是「引擎认为一样好」

对 49 份报障去重后的 34 点做分类（`_score_discard` 分量 + 破平层行为）：

| 类别 | 点数 | 含义 |
|---|---|---|
| A 主分被破平层**覆盖**（严格低于最优） | 4 | seq53/55/113/197 |
| **B 主分并列（破平层定，引擎认为一样好）** | **18** | seq5/6/17/22/45/47/57/78/80/121/124/135/150/160/163/164/198/201 |
| C 主分**严格最高**仍被质疑 | 9 | seq7/22/31/65/71/141/183/184/186 |
| skip（非出牌/不可复现） | 3 | seq62/116/127 |

- **B+C = 27/34（79%）是「引擎自认为选了最好」的点** ⇒ 缺陷在**估值函数**，不在破平层。
- 其中 **18 点（58%）是多候选、形质全并列**。
- 例（`/tmp/decompose.py` 输出）：seq45 手 `1w3w5w7w7w9w 2b 7b8b9b9b 2t 6t7t`，v5 选 9w、主分最高 1w，**但 1w/9w/2b 三者 total 全 = −26.21**（形质 4.97、喂牌 0.39 全同）；seq80 手含 `1b2b2b` + 孤张 `8b`，v5 选 8b，`1b/2b/8b` 三项 **total 全 = −17.78**。

## 4. 与用户直觉的关系

用户主张**高度一致**：**优先打「绝对孤张」，保留可塑性高的复合搭/对子/两面**（多次用豆包/DeepSeek 交叉验证）。
- 这正是 `shape_value` **应该**编码、但**没编码**的信息：
  - 打孤张 → 复合搭全保留 → 形质应更高；
  - 打复合搭的一环 → 破坏一块 → 形质应更低。
  - 但 `shape_value` 取「最好的 need 个块」且幅度 <1，**顶部落入并列** ⇒ 上述差异被抹平。
- 因此用户看到的「明显不合理」= 引擎在**无法区分**时，退回到与牌效无关的**喂牌/索引**。

## 6. 建议（供用户选择）

1. **【首要】增补「孤张/块保留」评分项**（直接对应本批报障，A 属立项）
   - 症状：`_score_discard` 的形质项对「打孤张 vs 破复合搭」无分辨力（40% 出牌点并列）。
   - 提案：在形质项加两个**量纲<1 的次排序修正**——① 保留块的**总量**质量（不止前 `need` 个）；② 被弃牌的**块贡献损失**（孤张损失 0，破块损失为正）。
   - 验证：`tools/trigger_counterfactual.py --mode discard --force-tile`（条件对拍，功效≈整场 A/B 的 10×）在**报障点 + 全量触发点**上量净分；正且 t≥2 才立默认档。
   - 预期：用户主张的 27 个 B/C 点里，B 组（并列）应多数朝用户方向移动。
2. **【次】副露估值**（"何时吃碰"用价值而非向听）—— 天花板更高（我们副露少 43%、胡牌 21% vs 26%），但 `v7m` 证明「放宽闸门」无效，需换判据（同属估值问题）。
3. **不要**做「破平层整体关闭 / maxtotal」：对拍 −1.381（t−1.11，NS，剂量-反应负）。
