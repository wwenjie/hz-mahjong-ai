## 1. 问题（已用 6 点分项分解证实）

出牌主分：`total = −10×向听 + 形质(shape_value) − 3×喂牌 − 财神罚`。
`shape_value` **只为"块"打分**：两面 1.2 / 对子 1.0 / 坎张·边张 0.7 / 财神 1.4；
**孤立张不构成块 ⇒ 恒贡献 0**。

⇒ 后果链：
1. 所有孤立张在形质层**完全等价**；
2. 排序退化到**喂牌项**（`visible_need×threat`，方向＝"中张危险/边张安全"，**与牌效率部分相反**）；
3. 喂牌也打平时退到**牌索引**（花色+点数最小者）。

## 2. 修复目标

让**孤立张**按其**连接性（有效进张数/种类）**估值，而不是恒 0。判据 = 用户与
豆包/DeepSeek 一致的**牌效率口径**（如：1b 靠 2b3b→8 张；9b 靠 7b8b，但 8b 已见 1 ⇒ 9b 相对更弱）。

## 3. 设计（最小改动、遵守既有纪律）

**新增一个「孤张连接性」项** `isolated_value`，并入形质返回值：

```
shape_value = 2×面子 + Σ(块权重) + isolated_value
```

`isolated_value` 建议定义（每张**未被任何块占用**的孤张）：
- 按其**可成搭的活牌种数**计（**只看牌种、不数张**，与 `shape_value` 的"种数"语义一致，避免引入"已见张"这类需要局面信息的东西——`shape_value` 签名只有 `counts`）：
  - 中张孤张（如 4w/5w/6w：能连 3 种邻张）> 边张孤张（如 3w/7w：2 种）> 幺九孤张（1w/9w：1 种，仅边搭）> 字牌孤张（0 种，除非对子）。
- 也可用「到最近搭子/顺子骨架的距离」近似；但**种数**口径最简单、可解释、可测。

**硬约束（沿用 `shape_value` 既有设计纪律）**：
1. **幅度 < 1**：`isolated_value` 的取值范围必须 **< 1 分**，保证**只打破并列、绝不覆盖
   "块数差 1"**（块的权重最小 0.7 ⇒ 块数差已 ≥0.7；如实测中 seq7 的 6.27 与 5.24 差约 1.03）。
2. **参数化 + 默认关**：新增 `PolicyConfig.isolated_connectivity: float = 0.0`（默认 0 ⇒ 逐位等于旧行为），
   值 ∈ [0, 0.9]。这是 A 车道惯例（默认关的实验臂）。
3. **一次只改一个机制**：本改动只碰 `shape_value`（或其调用点），不动喂牌项、不动破平层口径、
   不动向听权重。喂牌项是否仍主导（seq141 的 0.71 分差）**本轮不动**——先看连接性项能否在
   "形质并列 / 形质接近"的点上纠正（seq7/65/71/150），seq141 这类"喂牌覆盖"另立一臂。
