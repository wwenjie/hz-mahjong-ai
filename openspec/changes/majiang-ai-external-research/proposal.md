# Proposal — 外部麻将 AI 研究驱动的优化方向

## Why

2026-09-29 17:55 用户指派 B' 调研线上麻将 AI 论文/研究，寻找策略优化头绪。调研产物：
`agent/agentb-coordinator/out/mahjong-research-brief.md`（Suphx arXiv:2003.13590 全文、
Gao et al. 2019 arXiv:1906.02146、Sanma RL 摘要）。

调研结论：本仓当前主线（统一期望得分 / 形质分辨力 / 对手占用估计）与文献主流做法**同向但不重合**——
文献给出了三条我们尚未采用、且与现有工作互补的优化方向。本变更把这些方向固化为带前提、
带判据、带负责人的提案，避免散落在 THREAD 消息里被冲走。

背景状态（调研时点的三方共识）：

- 中段出牌决策 97.25% 由喂牌单键决定（B' 14:05 决策轨迹复算，36,941 点），形质项几乎无分辨力；
- `shape-blocks` 是唯一家族级正结果（n=3，+0.350 t3.19），A 已开 n=10 确认批；
- 对手占用模型（静态 34 维特征 + GBDT）两跑 No-Go（hat 一致率 73.2%/74.6% < 零信息基线 77.0%/77.8%），
  C 已自证特征集**无顺序/时近性维度**，No-Go 只 scoped 到静态聚合特征；
- 对手真名不下发、AI 昵称可得（`seats[].name`），榜单在门户 OpenID API（我们只用玩家 API）。

## What Changes

三条优化方向，按「文献依据 → 我们的缺口 → 提案 → 前提/判据 → 归属」固化：

### D1：弃牌一致率监督学习（Gao 2019 路径）

- **文献**：Gao et al. 2019 用 CNN 监督学习高手弃牌，测试一致率 70.44%（前 SOTA 62.1%），
  组合吃碰杠立直模型后天凤 rating ~1850。证明「弃牌」是可监督学习的，标签=高手实际弃牌。
- **我们的缺口**：出牌评分函数是手调的（且已退化）；从未试过「直接学该打哪张」。
- **提案**：用已采集的 353+ 房真机数据训弃牌分类模型（GBDT/CNN），标签=强对手的实际弃牌，
  特征含局面 + 各对手弃牌纹理。产出既可作独立决策器，也可作统一期望得分的对照基线。
- **前提（硬阻塞）**：需要玩家强度标签。链条 = ① 平台 `seats[].name` 给出 AI 昵称 →
  ② 门户 OpenID 拉榜单 → ③ 昵称↔榜单映射验证。**当前 ① 待实测、②③ 依赖门户接入**。
  在链路打通前**挂起**，不占队列。
- **判据（预登记，待链路打通后细化）**：留出集一致率显著高于启发式基线（先测 62% 一线）；
  再进四座位旋转 A/B。
- **归属**：依赖解除后，特征/训练归 C，登记签归 B'，决策器集成归 A。

### D2：Oracle guiding 蒸馏（Suphx 路径，替代「在线估占用」）

- **文献**：Suphx 用能看全信息的 oracle agent 训上界策略，逐步撤掉完美信息蒸馏成正常 agent。
  把「估对手暗手」从在线推理问题变成离线蒸馏问题，绕开「在线估不准」的死结。
- **我们的缺口**：C 的占用模型两跑 No-Go，且 No-Go 被 scoped 在静态特征上；
  在线估暗手这条路天花板低。
- **提案**：离线用全信息（模拟器内可知四家手牌）训一个「先知」策略上界，
  再蒸馏出只用公开信息的策略。**这是研究方向，不是已验证做法**——Suphx 用它做训练加速，
  我们挪来做占用/威胁的替代，文献无直接先例。
- **前提/判据**：需要全信息训练管线（模拟器已有）+ 蒸馏管线（新建）；
  判据 = 蒸馏后策略 vs 当前冠军 v3 的四座位旋转 A/B（机制门先行）。
- **归属**：RL/NN 线（`majiang_rl` 或本仓 research/** 由 C 牵头），B' 出蒸馏判据设计，A 集成。
  **成本高于 recency 特征**，建议与 D3 并行而非互斥。

### D3：占用估计加 recency/顺序特征（文献的显式编码路径）

- **文献**：Suphx/Gao 均**不用**序列模型处理弃牌顺序，而是把「近期弃牌」编成显式特征
  （Gao：每家最近若干张独立通道；Suphx：当前巡 + 近期弃牌显式编码）。
  文献中**没有**「麻将对手建模必须用 RNN/Transformer」的证据。
- **我们的缺口**：C 的 34 维特征是纯计数，无任何顺序/衰减维度（C 18:26 自证）。
- **提案**：特征加 ① 各对手最近 k 张弃牌 indicator、② 时间衰减计数 `Σ λ^Δt`、
  ③ 距上一张同牌种弃牌的巡数；同批房重跑。
- **判据**：hat 一致率须**显著超过**单变量 seen 查表基线（72.8%）与零信息基线（77.8%）；
  若仍不过 ⇒ 树模型路线关闭，占用线整体转入 D2。
- **归属**：C 已在跑（不占 A 队列）；B' 已给文献背书（THREAD 18:40）。

### 并行的主线（不在本变更内新增，仅登记依赖关系）

- **统一期望得分**（B' 设计稿 `agent/agentb-coordinator/out/unified-expected-score-design.md`，
  THREAD 18:45）：Suphx look-ahead 的手工因子版。D2/D3 的产出（占用/威胁估计）是它的**输入**，
  不阻塞；D1 若解锁是它的**对照基线**。
- **shape-blocks n=10 确认批**（A 在跑）：判据「n=10 合并 t≥2 才采纳，否则永久关闭
  ukeire*/shape*/feed*/seen-tiebreak 全族」。

## 非目标

- 不改 `src/**`（本变更只固化方向与判据；实现按分工归 A/C）；
- 不引入门户 OpenID 接入（D1 的前提，需用户/部署侧另行决策）；
- 不重启/新建任何打平台的进程。

## 风险

- **D2 成本最高**：全信息上界策略 + 蒸馏管线是新建工程，且文献中它是训练加速手段而非占用估计手段，
  挪用强度要在立项时标清；
- **D1 可能长期挂起**：若门户接入或昵称映射拿不到，这条线 indefinitely blocked，应设检查点
  （建议：海选 10/10 前若未解锁则正式关闭）；
- **三方向与主线的资源竞争**：核预算已超订 1.4×（A 15:20），D2/D3 的离线训练须遵守 §5.4
  （`nice -n 15`+ 串行重活），跨仓臂按 §5.6 代登记。
