# Proposal

## Why

仓库已有两条人力线：A 负责策略主线与运行时，B 负责独立复算与提交物。当前缺口是**长时间无人值守的迭代吞吐**——RL/NN 路线（训练 → 对拍 → 回归 → 再训练）天然是「跑很久、看结果、再调」的循环，靠人工驱动成本高；且 10/8 12:00 提交截止前，稳定性演练与日志巡检这类需要反复执行的活会持续挤占 A/B 的注意力。

本地部署 OpenClaw（下称「小龙虾」）作为第三条线：接入公司 CodeMaker 模型，通过本机 Web 控制台指挥，承担验证、稳定性、策略/运行时开发、值守告警与 RL/NN 研究。选它而非再开一个人工会话的原因是可挂后台长跑、可定时自触发、产出可审计。

## What Changes

- **新增 OpenClaw 本地部署**：WSL2 内以 npm 全局安装 + systemd 用户服务常驻，只监听本机，仅启用本地 Web 控制台（不接任何外部消息平台）。
- **新增模型接入**：以 CodeMaker Hub 本地代理（OpenAI 兼容 `/v1`）为主链路，`baseUrl` 与端口写成可配置项 + 启动自检；Hub 不可达时回退直连内网 API 端点。
- **新增 Agent 工作区与边界文件**：`AGENTS.md` 固化项目上下文、工作流与**禁入区**（合规红线、A/B 文件所有权、令牌纪律）。
- **新增仓库技能包**：把已有的 `openspec` 工作流、`pytest` / `selfplay` / `calibrate`、`verify/` 复算、日志巡检封装成小龙虾可直接调用的技能。
- **新增 RL/NN 研究线**：引入 dev-only 训练依赖（CUDA torch），产出**纯 Python 可推理**的模型产物（沿用现有 `strategy/gbdt.py` 的导出模式），并强制与现有 value/risk 基线对拍后才允许进策略。
- **新增值守与告警**：只读巡检比赛进程与日志，异常时把结构化摘要推到控制台；**不启动任何访问比赛平台的进程**（避免与 A 抢令牌桶）。

## Capabilities

### New Capabilities

- `openclaw-gateway`: OpenClaw 在本机 WSL2 内的安装、常驻、控制台访问与模型 provider 接驳能力，含启动自检、配置校验与不可达时的回退。
- `agent-workspace`: 小龙虾工作区与 `AGENTS.md` 约定能力——项目上下文注入、所有权边界、禁入区、记忆与技能装载。
- `mahjong-agent-skills`: 面向本仓库的技能包能力——OpenSpec 工作流、测试与自对弈、独立复算、日志巡检、训练脚本调用的标准入口。
- `rl-nn-pipeline`: 离线神经网络/强化学习训练与评估管线能力——数据构造、GPU 训练、模型导出为纯 Python 推理、与启发式基线对拍后才可进入策略候选。
- `ops-watch`: 只读值守与告警能力——比赛进程与日志巡检、异常归类、结构化上报，且对平台零请求。

### Modified Capabilities

（无。`openspec/specs/` 当前为空，本变更只引入新能力，不改动既有 spec 行为。）

## Impact

- **新增文件**：仓库内 `agent/`（`AGENTS.md`、技能定义、部署脚本、systemd 用户单元）；仓库外 `~/.openclaw/`（主配置、工作区、日志，**不入仓**）。
- **外部依赖**：Node.js（本机已有 v24.21.0）、OpenClaw npm 包；模型链路依赖 CodeMaker Hub 本地代理（Windows 侧运行，WSL2 经宿主 IP 访问）。WSL2 当前为 NAT 模式，Hub 端口在当前 WSL 内**尚未监听**，可达性与端口需实测确认。
- **新增 dev 依赖**：`torch`（CUDA，仅训练用）。**运行路径的零依赖约束不变**——`src/majiang/**` 仍只使用标准库。
- **凭据**：Hub 用固定占位 token（`codemaker-managed`，非真实凭据）；任何真实令牌只写 `~/.openclaw/openclaw.json` 与 env，不入仓、不入日志。
- **所有权边界**：不修改 A 的策略/运行时文件，不修改 B 的 `verify/**` 与稳定性测试；小龙虾新增工作落在 `agent/` 与新的研究目录。
- **合规红线（硬约束）**：推理输入仅限公开信息，不得持有/读取/推断对手手牌；离线训练中对手手牌只作标签。
- **硬件约束**：RTX 5060 Ti 8GB 显存，模型规模需在此预算内。
- **时间约束**：10/8 12:00 提交截止；10/10 首轮；10/12 决赛圈。
