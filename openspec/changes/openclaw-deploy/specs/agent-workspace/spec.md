# Spec Delta

## Purpose

定义小龙虾工作区的文件约定与所有权边界，使其在无人监督长跑时仍能自我约束、不越界，并且每次冷启动都自带足够的项目上下文。

## ADDED Requirements

### Requirement: 工作区结构齐备

工作区 SHALL 包含操作手册（`AGENTS.md`）、行为基调（`SOUL.md`）、用户偏好与背景（`USER.md`）、工具与入口说明（`TOOLS.md`）四类文件；四者职责 MUST NOT 互相混写。

#### Scenario: 冷启动加载

- **WHEN** 一个新会话开始
- **THEN** 代理在首个动作之前已读取操作手册，其行为符合其中的工作流与禁入区

#### Scenario: 职责不混写

- **WHEN** 检查操作手册与行为基调文件
- **THEN** 操作手册只含工作流、质量标准与边界，语气设定只出现在行为基调文件中

### Requirement: 禁入区显式声明

操作手册 SHALL 显式列出禁入区，至少覆盖：其他人力线负责的策略与运行时文件、独立复算与稳定性测试文件、守护与巡检脚本、文档目录、访问比赛平台的进程、以及运行路径的零依赖约束。

#### Scenario: 越界任务被拒

- **WHEN** 任务要求修改禁入区内的文件
- **THEN** 代理拒绝执行，说明原因，并给出不越界的替代做法

#### Scenario: 合规红线被拒

- **WHEN** 任务要求读取、导出或推断对手手牌用于在线推理
- **THEN** 代理拒绝，并引用「推理输入仅限公开信息」这一约束

#### Scenario: 平台请求被拒

- **WHEN** 任务要求启动或重启访问比赛平台的进程
- **THEN** 代理拒绝并指出该动作由既有守护脚本负责

### Requirement: 项目上下文自足

操作手册 SHALL 内联项目上下文：仓库定位与提交截止时间、测试与自对弈的标准命令、独立复算入口、日志目录与格式、令牌只经环境变量传入。

#### Scenario: 命令与实际一致

- **WHEN** 询问如何运行测试、自对弈或复算
- **THEN** 代理给出的命令与仓库当前实际入口一致，无需用户补充

#### Scenario: 令牌处理正确

- **WHEN** 任务涉及连接比赛平台所需的令牌
- **THEN** 代理只从环境变量读取，且不把令牌写入命令历史、文件或日志

### Requirement: 工作区可回溯

工作区 SHALL 纳入版本控制，操作手册、记忆与技能的每次变更 SHALL 留有可追溯的提交记录。

#### Scenario: 变更可追溯

- **WHEN** 查看工作区版本历史
- **THEN** 操作手册与技能文件的变更各自对应至少一次提交，且提交信息说明变更动机

### Requirement: 产出物落位

代理产出 MUST 落在仓库既有约定位置：变更提案进 OpenSpec 变更目录，复盘进笔记目录，可复用工具进工具或复算目录。

#### Scenario: 无散落文件

- **WHEN** 一个任务完成后统计新增文件
- **THEN** 全部位于上述约定目录内，工作区根目录不出现临时脚本或草稿文件
