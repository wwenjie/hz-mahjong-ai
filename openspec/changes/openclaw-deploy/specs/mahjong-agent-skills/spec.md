# Spec Delta

## Purpose

把本仓库的开发闭环（提案、测试、自对弈、独立复算、日志巡检、训练）封装成小龙虾可直接调用的技能，减少每次会话重新摸索命令与口径的成本，并强制沿用已有的统计纪律。

## ADDED Requirements

### Requirement: 变更流程技能

SHALL 提供覆盖「建提案 → 写规格与设计 → 拆分任务 → 实施 → 校验 → 归档」的技能入口，其命令与仓库使用的命令行工具实际行为一致。

#### Scenario: 走完整流程

- **WHEN** 要求为一个新需求建立变更提案
- **THEN** 技能按顺序产出提案、规格、设计与任务，且校验通过

#### Scenario: 命令漂移被发现

- **WHEN** 命令行工具的可用子命令与技能记录不一致
- **THEN** 技能报告不一致并停止，而不是猜测命令

### Requirement: 测试与自对弈技能

SHALL 封装测试、自对弈、校准与强度测量入口；调用结果 MUST 附带样本量与噪声底，MUST NOT 只给出点估计的提升幅度。

#### Scenario: 小样本不给结论

- **WHEN** 结果样本量低于噪声底要求
- **THEN** 输出判定为「不显著」，不输出「提升若干百分比」这类结论

#### Scenario: 强度对比带口径

- **WHEN** 完成一次自对弈强度对比
- **THEN** 输出包含对局数、置信区间或噪声底、以及对比双方决策器档位

### Requirement: 独立复算技能

SHALL 通过复算目录的入口从原始事件流复算指标；复算路径 MUST NOT 导入或复用策略主线的测量脚本与回放实现。

#### Scenario: 独立性可验证

- **WHEN** 审计复算调用链的导入
- **THEN** 不出现策略主线的测量脚本或回放模块

#### Scenario: 数字冲突被报告

- **WHEN** 复算结果与主线测量结果不一致
- **THEN** 技能同时报告两个数值与各自口径，并标记为需人工裁定的冲突

### Requirement: 日志巡检技能

SHALL 支持按事件类型检索结构化日志并汇总计数与时间分布；输出 MUST NOT 包含令牌或其他凭据。

#### Scenario: 按事件检索

- **WHEN** 请求检索决策、错误与超时三类事件
- **THEN** 输出各类数量、时间范围与代表性样例，且样例中不含令牌

#### Scenario: 数据增长可识别

- **WHEN** 两次巡检间隔内日志文件数或事件序列范围变化
- **THEN** 输出给出快照指纹（文件数与序列范围），避免把数据增长误读为行为退化

### Requirement: 训练脚本技能

SHALL 提供数据生成与模型训练的标准调用入口，并强制显式传入输出路径与随机种子。

#### Scenario: 同种子可复现

- **WHEN** 以相同随机种子重复执行同一数据生成入口
- **THEN** 产出摘要一致

#### Scenario: 缺少种子时拒绝

- **WHEN** 调用训练或数据生成入口但未提供随机种子
- **THEN** 技能拒绝执行并说明随机性会影响结论可比性
