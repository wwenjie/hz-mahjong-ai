# Proposal

## Why

主仓策略线（A/C）已把**规则启发式**打磨到很强的局部最优，并实测关闭了三条常见增强路径（出牌近邻重排、响应局部重排、PIMC 前瞻）——全部同向显著为负。但**真机天梯显示我们接近垫底**（用户 2026-09-28 提供：v3 身份 `凤凰-5531` 60 场 2 胜、排 114/115；同榜多家 RL 系 AI 名次远高），说明**"启发式难被超越"只是自对弈内部结论，真机裁决相反**。自对弈是有偏判据（`notes/OWNERSHIP.md` 已记）。

同时，独立仓 `majiang_rl`（NN/RL 研究线，对主仓只读）已产出真实证据：

- 三条模型臂（BC / RL / MLP-value）**叠在冠军 v3 之上全部显著为负**（名次分 −1.0 ~ −4.3/场）；
- 近邻偏好探针显示**微调无信号**（gap=1 胜率 53.5%，t+0.21）；
- ★ **全局回报预测探针（本提案的核心新证据）判读 GO**：仅凭当前公开局面的 29 维特征，可**显著但微弱地**预测**整场最终名次分**（Pearson r = +0.098，按场 bootstrap 95%CI [+0.037, +0.151]，训练集对照 +0.165，R² ≈ +0.01）。

⇒ 结论：**问题不在"训练不够"，而在"动作空间与奖励设计"**。需要一个有据可依、可迭代的**研究线提案**，把方案、路线图、文献台账固化下来，避免重复投入与结论漂移。

## What Changes

在主仓 `openspec/` 下新增研究线变更 `majiang-ai-nnrl`，**只维护提案文档，不改任何策略/运行时代码**：

1. **固化当前方案**：残差式 RL/BC（只重排「出牌」、其余动作委托启发式）+ 与主仓同口径的配对自对弈评测。
2. **固化路线图**：把"下一步做什么、判据是什么、Go/No-Go 阈值"写成可勾选任务（含**全局回报预测器**、**名次/序数奖励**、**对手池**、**外部专家锚**四条候选）。
3. **固化文献台账**：已看过 / 打算看的论文与开源麻将 AI（全部附 arXiv 号与证据等级），作为决策依据与"避免重走"清单。
4. **记录本提案的实证基线**：引用 `majiang_rl` 的探针/对拍产物路径，使每条主张可复算。

## Capabilities

### New Capabilities

- `return-predictor`: 整场回报预测器（Suphx「global reward prediction」式）——由当前公开局面预测本场最终名次分，用作优势估计的代替信号。含预登记判据与按场聚簇的置信区间。
- `residual-rl`: 残差式策略改进——在启发式冠军之上仅重排「出牌」，胡/杠/碰/吃/响应委托启发式；含 KL 锚、名次奖励、对手池等消融开关。
- `nnrl-eval`: 与主仓同口径的独立评测——四座位旋转配对自对弈、按房聚类、噪声底口径、跨种子方向一致性判据。

### Modified Capabilities

（无。本变更只新增，不修改 `majiang-ai` 与 `majiang-ai-agent-b` 已确立的能力。）

## Impact

- **新增文件**（仅文档）：`openspec/changes/majiang-ai-nnrl/**`。
- **不触碰**：`src/majiang/**`（A 的所有权）、`verify/**`、`scripts/**`、`docs/**`（C 的所有权）、`notes/agent-*.md`（各自追加）。本提案不在主仓写任何代码。
- **算力纪律**：本线所有重活 `nice`、**同一时刻只跑一个**，比赛期间机器只跑参赛程序（A 的真机诊断已确认算力竞争会浪费速率额度）。
- **合规红线**：特征只用公开信息 + 本人手牌；决策器**不得**实现 `observe_state`（不得读对手暗牌）。
- **仓边界**：实现落在独立仓 `majiang_rl`（对主仓只读，由 `src/nnrl/paths.py` 代码强制）；本提案只做记录与协调。
