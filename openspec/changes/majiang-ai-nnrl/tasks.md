# Tasks

> 约定：实现全在独立仓 `majiang_rl`（对主仓只读）。本提案只跟踪进度与判据。
> 纪律：所有重活 `nice`、同一时刻只跑一个；判决用低方差机制量 + 跨种子方向。

## 0. 已完成的基线（本提案的实证起点）

- [x] 0.1 三臂（`rl`/`mlp-value`/`policy-bc`）**vs 冠军 v3** 对拍：四座位旋转、20 场 × 2 种子
      → `majiang_rl/records/ab-arms-vs-v3.json`。**结论：三臂两种子全部显著负**（名次分 −1.0 ~ −4.3）。
- [x] 0.2 `search-v3`/`search-deep-v3` vs v3 对拍（含对照场）→ `records/ab-search-v3-vs-v3.json`、
      `records/ab-search-v3-field.json`。**结论：同向显著负**，命中预登记规则 1。
- [x] 0.3 近邻偏好探针 → `records/probe-pref-pairs.json`。**结论：gap=1 无信号（t+0.21）**。
- [x] 0.4 ★ **全局回报预测器 Go/No-Go** → `records/probe-return-predictor.json`。
      **判据（预登记）**：按场 bootstrap 95%CI 不含 0 且 > 0 ⇒ GO。
      **实测**：r = **+0.098**，CI **[+0.037, +0.151]**，训练集对照 +0.165，R²≈+0.01，名次对半准确率 0.530
      ⇒ **GO（但信号弱，仅用于"筛掉无信息方向"，不可直接当策略）**。
- [x] 0.4b **放大复核**（120 训 / 40 验）× 8 局，n_train=31746 → `records/probe-return-predictor-big.json`。
      **结果**：r = **+0.136**，CI **[+0.058, +0.219]**（不含 0，方向与小样一致）；R²=0.018；名次二分类 0.525。
      **分段**：early 0.162 / mid 0.089 / late 0.097 ⇒ 预测力随进度衰减（与小样桶口径不同，已写入 design 风险）。
- [x] 0.5 文献台账建立（见 `design.md` §文献台账，37 条，含证据等级）。

## 1. 回报预测器（能力 `return-predictor`）— 深化与用起来

      按场聚簇 bootstrap CI。含**训练集对照**与**进度分桶**（防"被前盘噪声稀释"的误判）。
- [ ] 1.2 **加"累计领先/落后"作为特征**（若平台在决策时可获得）或**显式改为"从第 r 局起预测剩余回报"**
      ——验证 r 是否显著提升（**放大复核实测**：early 段 r=0.162、mid 0.089、late 0.097；即开局好预测、中后段衰减）。
- [ ] 1.3 **口径升级**：把标签从"整场累计名次分"拆为**逐局增量名次分**，测预测器能否分辨"这局打得好不好"
      （Suphx 原意：区分"战术性输局"与"打错"）。
- [ ] 1.4 预登记阈值写死：r 的 CI 下界 > 0.05 才进入"用作优势估计"的下一阶段；否则**止损**。
