# Spec Delta

## Purpose

定义**残差式策略改进**能力：在既有启发式冠军之上，**只重排「出牌」**这一动作，其余动作委托启发式。这是 M 线整段替换失败（名次分 −3.4 ~ −4.3）后唯一被证据支持的架构选择（与 Meowjong 同构）。

## ADDED Requirements

### Requirement: 增量而非替换

决策器 SHALL 先询问启发式内层；**仅当**内层选择的是「出牌」且当前有摸牌时，才允许在其候选集内重选；其余动作（胡 / 杠 / 碰 / 吃 / 响应）SHALL 原样返回内层结果。

#### Scenario: 非出牌动作不被网络改写
- **WHEN** 内层返回的动作不是 `discard`（例如胡、杠、碰、吃、过）
- **THEN** 决策器原样返回该动作，网络不参与

### Requirement: 起点等价

初始（未训练）参数 SHALL 使决策器**逐位等价**于启发式内层（修正分支零初始化），从而构造上保证**不劣于起点**，不出现整段替换式的崩盘。

#### Scenario: 起点回归
- **WHEN** 用零初始化参数对拍起点
- **THEN** 名次分 / 胡次数 / 白板数与启发式**逐位相等**

### Requirement: 合规

决策器 MUST NOT 实现 `observe_state`，MUST NOT 读取对手手牌，只能用公开信息与本人手牌构造候选特征。

#### Scenario: 红线
- **WHEN** 构造候选特征
- **THEN** 与线上决策同源（`candidate_features`），且不引入任何隐藏信息

### Requirement: 奖励信号

训练奖励 SHALL 使用**低方差序数信号**（名次分等价物）而非单局得分，SHALL 施加 batch 级优势归一。

#### Scenario: 奖励源消融
- **WHEN** 比较 reward ∈ {单局得分, 名次分, 名次分+胡次数}
- **THEN** 报告 `w3_norm`（参数漂移范数）轨迹与 A/B 名次分差；判据是"显著为负 → 不显著"的收敛，而非要求一次跑赢

### Requirement: 锚定与方差控制

训练 SHALL 支持可配置的**与启发式分布的 KL 锚**（权重 β）与**残差尺度约束**，用于检验"缺少 SL 锚导致退化"这一假说。

#### Scenario: KL 锚消融
- **WHEN** 扫 β ∈ {0, 0.1, 0.5}
- **THEN** 报告各档是否把"显著负"压为"不显著"；结论必须带样本量与跨种子方向
