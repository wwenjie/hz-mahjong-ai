## 关键教训（A 已犯过的错，B 复算时请重点怀疑）

这轮 A 有四次断言被后续数据推翻，每次都是被数据而非推理纠正：

| A 曾断言 | 实际 | 教训 |
|---|---|---|
| 自对弈说「策略已到局部最优」 | 真机证明我们是最弱的打法 | **自对弈是有偏的判据**，不能用来判定强弱 |
| 我们听牌率 83.6%，是活跃玩家最低 | 真值 21.3% | 事件流重建曾把 8 局铺在同一局面上跑，**派生指标全部作废重算** |
| `chase_baotou` 白丢胜率 | 反事实算出净赚 +3.8 分/局 | 假设要用反事实检验，不要靠直觉 |
| A/B 中 `no-chase` 有 2.8 点优势 | 只有 6 场/臂，p≈0.10 | **看样本量再下结论** |

因此 B 的复算**必须自己从原始事件流写代码**，不要 import A 的工具，否则同一个 bug 会在两处犯同样的错。

## 这个环境会周期性回收长跑进程（B 必读）

实测：A 的采集进程 01:51 被杀一次、03:05 收到 SIGTERM 优雅退出一次，**日志 0 个 Traceback、
dmesg 无 OOM** —— 不是程序崩了，是外部清理。`setsid` 也挡不住。

后果与对策：

- 从工具调用里起的长跑进程**都会这样消失**，必须挂守护循环（A 用
  `tools/collector_supervisor.sh`）
- `tools/collector_supervisor.sh`、`auto_session.py`、`watch_process.py` 归 A，
  **不要重启或杀掉它们**（`pkill -f` 还会命中你自己的 bash wrapper，A 已经自伤过一次）
- **任何「重启后从零开始」的计数器都会变成静默偏置**：A 的决策器轮换位置原本每次启动
  归零，于是重启后的第一场永远是 `deciders[0]`，交错 A/B 实际偏向第一个档位。
  已改为从账本恢复。B 写长跑脚本时请一并检查这一点

## 验收纪律（A 本轮犯过的错，全部同类）

A 这一轮被数据推翻 / 自己查出错的次数已到六次，**每一次都是「仪表错」而不是「结论错」**：

| 错法 | 表现 | 防线 |
|---|---|---|
| 固定座位的自对弈对比 | 把 treatment 固定坐 0 座，而 0 座就是庄家 → 测出 +5.7 个百分点的假优势 | 任何策略对比必须**四座位旋转** |
| 按文件抽样 | 40 文件只有 4 个房，而一个房四家固定 → 副露率差 24% | 抽样按**房**分层，不按文件 |
| 裸 `except` | 把「输入非法（12 张牌）」吞成「精确进张为 0」→ 报出「少进张 −30 张」 | **绝不吞异常**；荒谬的量级就是仪表坏了 |
| 量纲混用 | 廉价口径的进张数减精确口径的 → 报出「少进张 −14 张」 | 两个估计只能**各自取 argmax 再在统一口径下比较** |
| 短路副作用 | `all(place(...))` 只落一半面子 → 手牌变 15 张 | 多步状态变更要**先整体校验再落子** |
| 退化总体 | 构造的测试手牌恰好是听牌，而听牌时任何合法出牌听口相同 → 量纲参考恒为 0 | 构造总体后先确认它**有区分度** |

**三条通用判据**：① 出现「负张数」这类荒谬量级，先怀疑仪表；② 两个口径差得离谱时，
先在**同一批数据**上重跑再下结论；③ 任何指标在用于决策前，先在**已知答案的小样本**上验一次
（`tools/analyze_ukeire_fidelity.py` 就是这么发现 5.4 的结论建立在坏指标上的）。
